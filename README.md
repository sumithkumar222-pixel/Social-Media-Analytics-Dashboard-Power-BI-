📌 Project Overview

This project analyzes social media performance across multiple platforms (Instagram, Facebook, Twitter) to generate actionable insights on engagement, content strategy, and audience behavior.

🎯 Objectives

Track key engagement metrics

Identify high-performing platforms and content types

Analyze optimal posting time

Understand audience sentiment

📁 Dataset

Includes:

Platform

Post Type

Post Time

Likes, Comments, Shares

Sentiment Score

📊 Dashboard Features

KPI Cards (Total Engagement, Likes, Comments, Shares)

Platform Performance Analysis

Engagement Trends Over Time

Content Type Analysis

Best Day & Time to Post

Sentiment Analysis

Top Performing Posts

🔍 Key Insights

Instagram generates the highest engagement

Video and carousel posts perform best

Peak engagement occurs during evening hours

Majority sentiment is positive

Data Cleaning & Transformation
